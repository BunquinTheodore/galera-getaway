ABOUT THE WEBSITE

Galera Getaway

Galera Getaway is a travel guide for Puerto Galera, a popular destination in Oriental Mindoro known for its beaches and coral reefs. It collects places to visit, activities with prices, places to stay and the route from Manila in one site.

This website is a final project for CC 100, Introduction to Computing, at Batangas State University. It is built with HTML and CSS only.
